Current base path: /mnt/mmc

SD2 must be inserted when you install the archive, or the files will be written to internal storage.

When SD2 has a MUOS/ folder (bios, save, theme, music, and so on), muOS uses it instead of SD1's, so this archive will make SD2's copy the active one.
